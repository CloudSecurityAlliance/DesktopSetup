**Key findings:**
- **Telemetry, which ranks first in Kurt's order:** onnxruntime 1.29 and later ships Microsoft telemetry on by default,
  and **pymupdf 2.x requires onnxruntime**, as does markitdown. So the installer's unpinned `pymupdf` had been putting
  telemetry on staff machines since pymupdf 2.0, and it can't install on Intel Macs. The fix pins `pymupdf<2` and drops
  markitdown.
- **Windows has the same gap, live today** (#184's do-first comment).
- **uv traps:**
  - `uv python find` without `--system` returns an active venv's Python.
  - An exported `UV_PYTHON_PREFERENCE` makes uv refuse `--managed-python`.
  - BSD `mv` onto a symlink to a directory moves the source *into* that directory; `-h` is required.
  - A venv built at one path and renamed breaks `activate` and every console script; `uv venv --relocatable` survives
    the rename.
  - uv 0.13.7 creates `python3.14` shims.
- **CI skew:** local shellcheck 0.11 passes SC2120, where CI's 0.9.0 fails it (#186).
